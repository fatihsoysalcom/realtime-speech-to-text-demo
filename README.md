# Realtime Speech to Text Demo

This example demonstrates a basic realtime speech-to-text (STT) functionality using the Web Speech API. It allows users to start and stop listening, and displays transcribed speech in real-time in the browser.

## Language

`javascript`

## How to Run

Save the code as an HTML file (e.g., index.html) and open it in a web browser that supports the Web Speech API (like Chrome). Click 'Start Listening' and speak into your microphone.
